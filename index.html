Обо мне

Я учусь на первом курсе Санкт-Петербургского государственного университета аэрокосмического приборостроения. В IT меня больше всего привлекает момент, когда идея из головы превращается в работающую вещь, которой может пользоваться другой человек.

В этом семестре я научился вести базу знаний в Obsidian, планировать проект по методу Kanban, обрабатывать данные в таблицах и оформлять отчёты по ГОСТ. Этот сайт я сверстал вручную: без конструктора, чтобы разобраться, как устроены меню, сетка и формы.

Сейчас хочу подтянуть JavaScript и Git, а к концу года сделать небольшое веб-приложение для учёбы.

  • HTML, CSS, основы JS
  • Obsidian, Markdown
  • Kaiten, Kanban
  • Отчёты по ГОСТ
